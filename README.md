## 工作方式

1. **一次只推进一个阶段**，不并行。当前阶段没有结论，就不进入下一阶段。
2. **材料必须能回答问题。** 收集前先写下"我要用它回答什么问题"，答不上来就不收。
3. **决策进日志。** 方向、技术栈、范围变更都记一条，写清理由和放弃的备选。
4. 分工：我负责调研、整理、写代码、挑毛病；你负责提供真实信息、做取舍、承担结果。

## 一条重要的原则

> 面试官不关心你用了多少技术，只关心**你为什么这么选、遇到了什么、怎么解决的**。
> 所以从第一天起，每个阶段的"踩坑记录"都要留痕——这是后面写讲解稿的原料。
