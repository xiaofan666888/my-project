# 图片资源说明

## 当前使用的形象：`cat/`

5 张表情图，**完全由代码绘制**，无版权问题，可以安全地提交进公开仓库。

| 文件 | 表情 | 什么时候出现 |
|---|---|---|
| `cat/cat-normal.png` | 普通 | 默认状态 |
| `cat/cat-happy.png` | 开心 | 心情 > 76，且不饿不脏 |
| `cat/cat-angry.png` | 生气 | 饱食或清洁 < 18 |
| `cat/cat-sad.png` | 难过 | 心情 < 22 |
| `cat/cat-sleep.png` | 睡着 | 睡觉状态（待接） |

- 尺寸 512×512，透明背景
- 单张 45–51 KB，五张合计约 240 KB（主包上限 2 MB）
- 生成脚本见下方说明

### 表情是怎么选的

在 `pages/home/home.js` 的 `expressionOf()` 里，由三个数值决定：

```js
心情 < 22           → sad
饱食 < 18 或 清洁 < 18 → angry
心情 > 76 且都不缺     → happy
其余                 → normal
```

**这就是"数值是情绪底色"的具体落地**：数值不逼你回来，但决定它用什么脸看你。

### 形象是怎么来的

用 Pillow 以代码绘制（超采样 4 倍抗锯齿后缩放到 512），没有使用任何现成素材。

面试可以这么讲：
> "形象是参数化的：同一个函数根据表情参数画出眼睛、眉毛、嘴形的不同组合，所以加新表情只要加一个分支，不用重做图。"

## 想自己换形象的话

| 项 | 要求 |
|---|---|
| 格式 | PNG，背景透明 |
| 尺寸 | 512×512（或等比，高度 640 以内） |
| 体积 | 单张 < 100 KB |
| 命名 | `cat-normal / happy / angry / sad / sleep` |
| 来源 | 自己画 / CC0 素材（如 kenney.nl）/ 购买授权 |

换完只要保证文件名一致，代码一行都不用改。
