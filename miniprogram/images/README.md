# 图片资源说明

## 两套形象（可切换）

首页调试面板里有 **「切换形象：猫 / 我」**，选择存在本地，重启不丢。

| 目录 | 形象 | 来源 | 能否进公开仓库 |
|---|---|---|---|
| `cat/` | 橘猫 | 代码绘制 | ✅ 可以 |
| `me/` | 黑长直女生（本人形象） | 按真人照片的造型特征重新绘制 | ✅ 可以 |
| ~~`pet-minion.png`~~ | 小黄人 | 版权素材 | ❌ 已排除，勿提交 |

## 表情规则

两套形象都用同一套文件名，由 `pages/home/home.js` 的 `expressionOf()` 决定：

```
心情 < 22                → sad
饱食 < 18 或 清洁 < 18   → angry
心情 > 76 且都不缺        → happy
睡前/其他                → normal（sleep 已生成，待接入睡觉功能）
```

路径规则：`/images/{avatar}/{avatar}-{expr}.png`
换形象只要改 `avatar` 变量，代码一行不用动。

## 形象是怎么来的

**全部用 Pillow 以代码绘制**，没有使用任何现成素材。

- `cat/`：圆弧 + 多边形拼出的卡通猫
- `me/`：长发用一个椭圆表示，脸用内嵌的小椭圆"挖"出来，刘海是一道粗弧线

两者都是**参数化生成**的：同一个函数根据表情参数换眼睛、眉毛、嘴形的组合，所以加新表情只要加一个分支，不用重做图。

面试可以这么讲：
> "形象不是找的素材，是代码画的。所以加表情零成本，改配色也只是一个变量。"

## ⚠️ 关于真人照片

用户确实提供了本人照片，但**照片本身没有进入仓库**，只有按照片特征重绘的卡通形象进了仓库。

原因：
1. 公开仓库里的真人照片会被搜索引擎收录，无法撤回；
2. 卡通化后是原创作品，可以自由展示在简历和演示里；
3. 万一以后想给别人看代码，不会牵扯肖像问题。
