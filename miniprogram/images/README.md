# 图片资源说明

## ⚠️ 这里的形象不能进公开仓库

`pet-minion.png` 是**本地测试用**的形象，**受版权保护**（Minions © Universal / Illumination），
已在 `.gitignore` 中排除，不会出现在公开仓库里。

临时用它是为了验证"触摸反应"的手感，**上线或写进简历之前必须换掉**。

## 替换要求

| 项 | 要求 |
|---|---|
| 文件名 | `pet-minion.png` 改名为 `pet.png`（或改代码里的路径） |
| 格式 | PNG，背景透明 |
| 尺寸 | 高度 640px 左右，宽度按比例 |
| 体积 | 控制在 150 KB 以内（小程序主包上限 2 MB） |
| 来源 | 自己画 / CC0 素材（如 kenney.nl）/ 购买授权 |

换好之后，把 `pages/home/home.wxml` 里的 `src="/images/pet-minion.png"` 改掉即可。

## 自己做形象的三个建议

1. **简笔画也能用**：一个圆 + 两只眼睛 + 一张嘴，只要表情能变，就够做 v0.1。
2. **多准备几个表情**：开心 / 生气 / 难过 / 睡，各一张，用 `image` 的 `src` 切换。
3. **别追求精致**：面试官看的是交互逻辑和代码，不是一个 sprite 画得好不好。
